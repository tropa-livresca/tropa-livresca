# Documentação do Modelo de Dados (Supabase/PostgreSQL)

Este documento contém as diretrizes e instruções técnicas sobre o mapeamento estrutural das tabelas do banco de dados do projeto. Ele serve como documentação conceitual e guia de implantação para a arquitetura de persistência.

---

## Instruções para Execução e Implantação

Se você precisar recriar estas tabelas em um banco de dados limpo ou em um novo ambiente do Supabase, siga rigorosamente as diretrizes abaixo:

1. **Geração Automática de IDs (Identity):**
   - As sequências numéricas utilizam a cláusula nativa e padronizada `GENERATED BY DEFAULT AS IDENTITY`, eliminando dependências manuais de objetos sequenciais externos.
   - A tabela `users_profile` adota o tipo `uuid` integrado ao ecossistema do Supabase Auth para controle centralizado de chaves primárias.

2. **Chaves Estrangeiras Pendentes:**
   - Este documento foca estritamente na estrutura estrutural de criação das tabelas. Os comandos de amarração de chaves estrangeiras (`ALTER TABLE ... ADD CONSTRAINT`) devem ser executados apenas **após** a criação bem-sucedida de todas as entidades listadas na arquitetura.

3. **Esquema de Destino:**
   - Todas as entidades estão mapeadas explicitamente para o esquema `public`.

---

## Estrutura de Criação das Tabelas (DDL)

```sql
-- Tabela: users_profile
CREATE TABLE public.users_profile (
    id uuid NOT NULL,
    nome text NOT NULL,
    telefone character varying NOT NULL,
    imagem text,
    descricao text,
    redes_sociais jsonb,
    is_admin boolean NOT NULL,
    senha_adm text,
    primeiro_acesso boolean NOT NULL,
    email text,
    is_master boolean,
    dados_bancarios jsonb,
    CONSTRAINT users_profile_pkey PRIMARY KEY (id)
);

-- Tabela: notificacoes_lidas
CREATE TABLE public.notificacoes_lidas (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    fk_notificacao_id bigint NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    data_leitura timestamp with time zone NOT NULL,
    CONSTRAINT notificacoes_lidas_pkey PRIMARY KEY (id)
);

-- Tabela: usuarios_cartoes
CREATE TABLE public.usuarios_cartoes (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    token_pagamento text,
    final_cartao character varying NOT NULL,
    bandeira_varchar character varying NOT NULL,
    nome_no_cartao text NOT NULL,
    data_expiracao character varying NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    CONSTRAINT usuarios_cartoes_pkey PRIMARY KEY (id)
);

-- Tabela: itens_venda
CREATE TABLE public.itens_venda (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    qtd bigint NOT NULL,
    subtotal numeric NOT NULL,
    fk_livros_itens_id bigint NOT NULL,
    fk_vendas_id bigint NOT NULL,
    CONSTRAINT itens_venda_pkey PRIMARY KEY (id)
);

-- Tabela: comentarios
CREATE TABLE public.comentarios (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    data timestamp with time zone NOT NULL,
    texto text NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    fk_livros_id bigint,
    CONSTRAINT comentarios_pkey PRIMARY KEY (id)
);

-- Tabela: livros
CREATE TABLE public.livros (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    direitos_de_publicacao boolean NOT NULL,
    conteudo_por_IA boolean NOT NULL,
    imagens_explicitas boolean NOT NULL,
    numero_edicao smallint,
    data_de_publicacao date NOT NULL,
    preco_digital numeric NOT NULL,
    preco_fisico numeric NOT NULL,
    titulo text NOT NULL,
    subtitulo text NOT NULL,
    descricao text NOT NULL,
    autor_nome text NOT NULL,
    autor_sobrenome text NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    ativo boolean NOT NULL,
    estado character varying NOT NULL,
    idioma text NOT NULL,
    manuscrito text,
    colaboradores jsonb,
    capa jsonb,
    categoria text,
    ISBN text,
    palavras_chave text,
    numero_paginas smallint,
    CONSTRAINT livros_pkey PRIMARY KEY (id)
);

-- Tabela: avaliacoes
CREATE TABLE public.avaliacoes (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    data_criacao timestamp with time zone NOT NULL,
    fk_livros_id bigint,
    fk_users_profile_id uuid,
    qtd_estrelas smallint,
    CONSTRAINT avaliacoes_pkey PRIMARY KEY (id)
);

-- Tabela: vendas
CREATE TABLE public.vendas (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    data timestamp with time zone NOT NULL,
    total numeric NOT NULL,
    fk_met_pagamentos_id bigint NOT NULL,
    transacao_id text NOT NULL,
    status_pagamento text NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    endereco_entrega jsonb,
    status_entrega text NOT NULL,
    CONSTRAINT vendas_pkey PRIMARY KEY (id)
);

-- Tabela: movimentacoes_financeiras
CREATE TABLE public.movimentacoes_financeiras (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    data timestamp with time zone NOT NULL,
    fk_user_profile_id uuid,
    fk_vendas_id bigint,
    tipo text NOT NULL,
    valor numeric NOT NULL,
    descricao text NOT NULL,
    status text NOT NULL,
    CONSTRAINT movimentacoes_financeiras_pkey PRIMARY KEY (id)
);

-- Tabela: enderecos
CREATE TABLE public.enderecos (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    estado character varying NOT NULL,
    bairro text NOT NULL,
    rua text NOT NULL,
    num integer NOT NULL,
    cep character varying NOT NULL,
    fk_user_profile_id uuid NOT NULL,
    cidade text NOT NULL,
    complemento text,
    pais text,
    ativo boolean,
    principal boolean,
    CONSTRAINT enderecos_pkey PRIMARY KEY (id)
);

-- Tabela: met_pagamentos
CREATE TABLE public.met_pagamentos (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    nome text NOT NULL,
    CONSTRAINT met_pagamentos_pkey PRIMARY KEY (id)
);

-- Tabela: revisoes
CREATE TABLE public.revisoes (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    arquivo text NOT NULL,
    data_criacao timestamp with time zone NOT NULL,
    apontamento text,
    fk_user_profile_id uuid NOT NULL,
    fk_livro_id bigint NOT NULL,
    nome text,
    completado boolean NOT NULL,
    CONSTRAINT revisoes_pkey PRIMARY KEY (id)
);

-- Tabela: notificacoes
CREATE TABLE public.notificacoes (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    texto text NOT NULL,
    tipo text NOT NULL,
    data timestamp without time zone NOT NULL,
    ADM boolean NOT NULL,
    fk_user_profile_id uuid,
    titulo text,
    metadados jsonb,
    geral boolean NOT NULL,
    CONSTRAINT notificacoes_pkey PRIMARY KEY (id)
);
```

## Relacionamentos e Restrições (Chaves Estrangeiras)

As diretivas abaixo realizam as amarrações lógicas entre as entidades do ecossistema. Certifique-se de executar este bloco **apenas após** a criação de todas as tabelas listadas anteriormente.

```sql
-- Tabela: movimentacoes_financeiras
ALTER TABLE public.movimentacoes_financeiras
    ADD CONSTRAINT fk_movimentacoes_venda
    FOREIGN KEY (fk_vendas_id) REFERENCES public.vendas (id);

ALTER TABLE public.movimentacoes_financeiras
    ADD CONSTRAINT fk_movimentacoes_usuario
    FOREIGN KEY (fk_user_profile_id) REFERENCES public.users_profile (id);

-- Tabela: comentarios
ALTER TABLE public.comentarios
    ADD CONSTRAINT comentarios_fk_user_profile_id_fkey
    FOREIGN KEY (fk_user_profile_id) REFERENCES public.users_profile (id);

-- Tabela: itens_venda
ALTER TABLE public.itens_venda
    ADD CONSTRAINT itens_venda_fk_livros_itens_id_fkey

ALTER TABLE public.itens_venda
    ADD CONSTRAINT itens_venda_fk_vendas_id_fkey
    FOREIGN KEY (fk_vendas_id) REFERENCES public.vendas (id);

-- Tabela: vendas

ALTER TABLE public.vendas
    ADD CONSTRAINT vendas_fk_user_profile_id_fkey

-- Tabela: revisoes
```
